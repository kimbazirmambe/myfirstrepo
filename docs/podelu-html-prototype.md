# Локальный HTML-прототип для podelu.by

## Статус проверки сайта

При исследовании 9 ноября 2026 года запросы к `https://podelu.by/robots.txt` и `https://podelu.by/` получили ошибку `Tunnel connection failed: 403 Forbidden` от прокси среды Codex **до соединения с сайтом**. Это не подтверждает блокировку со стороны podelu.by. Правила доступа, наличие RSS/API/sitemap и реальная HTML-разметка не проверены.

Автоматическая загрузка сайта не реализована и не разрешается этим прототипом. CAPTCHA, блокировки и другие ограничения не обходятся. Перед будущим подключением нужно отдельно проверить robots.txt, условия сайта и разрешённый способ доступа. Robots.txt сам по себе не является лицензией на перепубликацию.

## Что работает сейчас

`src/collectors/podelu_html.py` — отдельный модуль на стандартной библиотеке Python, без Django и дополнительных зависимостей. Он принимает HTML как строку, а команда запуска читает **только локальный UTF-8 HTML-файл**. Сетевых запросов нет.

Используется пробное общее правило: искать ссылки внутри заголовков h1–h6 или ссылки, оборачивающие такие заголовки. Результат — **кандидаты** в статьи, а не подтверждённые статьи podelu.by. Разделы и категории тоже могут иметь такие заголовки; без проверки настоящей разметки их нельзя надёжно отличить от публикаций.

Извлекаются текст заголовка и полный URL. Вложенный текст и HTML-сущности учитываются. Отбрасываются ссылки на другие домены, служебные блоки nav/aside/footer, скрипты, шаблоны, пустые/неоднозначные заголовки и небезопасные схемы ссылок. Допускаются только HTTP/HTTPS на `podelu.by` и `www.podelu.by`, без учётных данных в URL. HTML-тег base не меняет переданный адрес страницы.

Повторы одинакового URL убираются; фрагмент `#...` не учитывается. Параметры запроса сохраняются, потому что их смысл на сайте пока неизвестен. HTTP/HTTPS, www и разные параметры запроса пока не объединяются. Удалённые страницы не проверяются. Даты, тексты статей, JavaScript, расписание и запись в SQLite не реализованы.

## Попробовать на учебном примере

Из корня репозитория, в Linux / macOS:

```sh
.venv/bin/python src/collectors/podelu_html.py tests/fixtures/podelu_sample.html
```

На Windows:

```powershell
.\.venv\Scripts\python.exe src/collectors/podelu_html.py tests/fixtures/podelu_sample.html
```

Если Python уже доступен отдельно, можно использовать просто `python`: модулю не нужны устанавливаемые пакеты.

Команда выведет JSON с двумя учебными заголовками и вымышленными адресами `/articles/demo-one/` и `/articles/demo-two/`. **Тестовый файл написан вручную и не является сохранённой страницей podelu.by.** Наличие этих адресов на сайте не предполагается.

Для своего локального файла:

```sh
.venv/bin/python src/collectors/podelu_html.py /path/to/saved.html --base-url https://podelu.by/news/
```

Адрес после `--base-url` — исходный адрес страницы для разрешения относительных ссылок; команда его не открывает. `/news/` здесь только пример, не проверенный раздел сайта. Указывайте реальный исходный адрес разрешённо полученного файла. Пустой JSON означает отсутствие подходящих кандидатов по пробному правилу, а не доказательство отсутствия новостей. Файл с другой кодировкой сначала сохраните как UTF-8.

## Тесты

```sh
.venv/bin/python -m unittest discover -s tests -p test_podelu_html.py -v
```

Тесты проверяют учебный HTML, заголовки, относительные ссылки, отсев внешних и некорректных адресов, устранение повторов, служебные блоки и команду чтения файла. Отдельная проверка запрещает создание сетевого сокета при разборе примера. Тесты не обращаются к сайту и не подтверждают совместимость с его текущим HTML.

Следующий шаг после подтверждения правил доступа — получить разрешённый образец настоящей страницы и проверить/уточнить правило выделения статей на этом образце. До этого включать автоматический сбор нельзя.
