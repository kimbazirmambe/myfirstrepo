# Агенты, навыки и плагины

## Роли агентов

`AGENTS.md` задаёт общие правила проекта. Именованные роли зарегистрированы в `.codex/config.toml`, отдельные инструкции хранятся в `.codex/agents/*.toml`. explorer и reviewer используют режим только чтения, developer наследует разрешения сессии. Модель намеренно не закреплена: используется доступная модель текущего клиента.

```powershell
python scripts/workspace.py new-agent researcher
```

Отредактируйте `.codex/agents/researcher.toml` и описание в конфигурации. Укажите назначение, входные данные и ожидаемый результат. Перезапустите сессию. Попросите Codex использовать роль явно. Наличие роли не означает автоматический запуск агента; доступность определяется версией клиента и политикой сессии.

## Навыки

```powershell
python scripts/workspace.py new-skill release-check
```

Получится `.agents/skills/release-check/SKILL.md` с обязательными полями `name` и `description`. В описании укажите, когда навык применять; в тексте — шаги и критерии успешности. Вызовите `$release-check` в новой сессии. Нужные скрипты можно хранить рядом с навыком; не включайте в него секреты.

## Собственные плагины

В проекте есть плагин `workspace-helper` с навыком `workspace-guide`. Он не требует сети, токенов и запуска внешних программ.

Для Codex CLI с поддержкой команды `plugin`:

```powershell
codex plugin marketplace add .
codex plugin add workspace-helper@myfirstrepo-local
```

Команды изменяют личную конфигурацию и устанавливают локальную копию плагина. Затем начните новую сессию и вызовите навык workspace-guide. Если команда отсутствует, обновите Codex по официальной инструкции; навыки `.agents/skills/` можно использовать отдельно от плагинов.

Создание своего плагина:

```powershell
python scripts/workspace.py new-plugin my-tools
```

Генератор создаёт `plugins/my-tools/.codex-plugin/plugin.json`, каталог `skills/` и запись в `.agents/plugins/marketplace.json`. Отредактируйте навык и описание, выполните проверки и установите `my-tools@myfirstrepo-local`. После изменения уже установленного плагина переустановите его, чтобы обновить установленную копию. Публикация каталога для других пользователей — отдельное действие.

Плагин может объединять навыки и MCP, но стартовый пример содержит только навык. MCP подключается по [отдельной инструкции](../integrations/README.md). Установка стороннего плагина не заменяет авторизацию в его сервисах.

## Проверки

```powershell
python scripts/workspace.py check
python -m unittest discover -s tests -v
```

Проверки покрывают связность файлов, генерацию расширений, сохранность существующих файлов, недопустимые имена и запросы к MCP. Они не проверяют качество текста инструкций и не подтверждают вход в сторонние аккаунты. GitHub Actions настроен для Linux и Windows; реальные результаты появятся после отправки изменений и запуска workflow.

Форматы сверены с установленным Codex CLI 0.167.0-alpha.4 и официальными исходниками OpenAI Codex. Возможности другой версии могут отличаться:

- [MCP](https://developers.openai.com/codex/mcp)
- [Исходники Codex](https://github.com/openai/codex)
