# Рабочий редакционный процесс Marketing Hub

## Доступ

Главная страница публична. Источники, статьи, материалы, журнал и настройки доступны только активным пользователям Django с `is_staff=True`. Регистрации посетителей нет. Вход выполняется через стандартную форму Django; создание администратора описано в README и инструкции PythonAnywhere.

## От источника до готового текста

1. В «Источниках новостей» сохраните адрес RSS или страницы сайта. Никаких источников автоматически не добавляется.
2. В «Найденных статьях» выберите «Импорт из файла» либо добавьте статью вручную. Импорт принимает разрешённо полученный UTF-8 RSS/Atom или локальный HTML podelu.by. До 1 МБ и до 100 записей за один импорт. Сервер не скачивает страницы и не выполняет JavaScript.
3. При импорте укажите включающие и исключающие слова, если они нужны. Проверяются заголовок и доступное описание. Пустой фильтр принимает все подходящие записи. Повторы нормализованного URL не создают новые статьи: убираются фрагменты и параметры utm_*, fbclid, gclid, сохраняются значимые параметры. Перепечатки по разным адресам пока требуют ручной проверки.
4. Откройте карточку статьи, изучите первоисточник, отметьте «Отобрана» или «Отклонена». Дата публикации может отсутствовать — она не заменяется датой импорта. Даты без указанного часового пояса трактуются как UTC; отображение также в UTC. Неизвестная или некорректная дата остаётся пустой.
5. Нажмите «Подготовить материал». Выберите формат: соцсеть, мессенджер или email. Напишите самостоятельный текст; для email обязательна тема. Ссылка на оригинал сохраняется отдельно и включается в экспорт.
6. Сохраните черновик. Проверьте факты, права на использование материала и поставьте флажок подтверждения, затем утвердите версию.
7. Скачайте текст в .txt. Это экспорт, а не публикация или рассылка. Система никогда не отправляет материалы автоматически.

Любое редактирование сохраняет новую версию и снимает утверждение. Утверждение фиксирует пользователя и время. Ранее сохранённые тексты доступны в истории; устаревшая вкладка не может перезаписать новую версию без обновления страницы. Удаление источника не удаляет уже сохранённые статьи и материалы.

## Что не подключено

ИИ-провайдер, периодический сбор, загрузка RSS по сети, Telegram, соцсети и email-сервисы не подключены. Интерфейс прямо показывает это. Материалы пишет человек; система не выдаёт шаблоны за результат ИИ. Подписчиков и персональных данных рассылок нет.

Отдельный HTML-прототип пока использует общее правило заголовков и возвращает кандидатов. При новой исследовательской проверке podelu.by главная и robots.txt стали доступны; robots.txt запрещает /api, /admin и другие служебные пути. Это не даёт права копировать статьи. Точные правила выделения статей и условия их использования необходимо проверить перед автоматизацией; импорт HTML остаётся ручным и требует проверки результата.

## Обновление существующего сайта PythonAnywhere

После принятия PR в main откройте Bash-консоль PythonAnywhere. Для установки на стандартных путях из прежней инструкции:

```bash
cd ~/myfirstrepo
git status --short
git pull --ff-only origin main
source ~/.virtualenvs/marketing-hub/bin/activate
python -m pip install -r requirements.txt
python scripts/update_pythonanywhere.py --apply
```

Если `git status` показывает собственные изменения, остановитесь перед pull: не удаляйте и не сбрасывайте их. Если pull или любая подготовительная команда завершились ошибкой, не продолжайте публикацию.

Скрипт использует существующий секретный файл `~/.config/marketing-hub/environment.json`, не печатает ключ, проверяет production-настройки, сохраняет резервную копию существующей SQLite в `.local/backups`, выполняет миграции и собирает CSS. Пользователей, источники и статьи не создаёт. Без `--apply` он только проверяет настройки.

После успешного выполнения нажмите **Web → Reload** у существующего сайта. Новые ресурсы и платные тарифы не нужны. Проверьте вход, список статей, редактор и историю. Пароли и API-токены не передавайте в чат.

Доступность старой главной страницы сама по себе не подтверждает установку новой версии. Новая версия установлена только после миграций, Reload и проверки новых маршрутов на сайте.
